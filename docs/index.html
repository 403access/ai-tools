Features

Everything at a glance

Two tabs, zero setup. OpenCodeBar reads the local OpenCode service and keeps itself up to date.

Live sessions

Running sessions update in real time over OpenCode's event stream, with a pulsing indicator, project, model, agent, elapsed time, and token count.

Recent history

Your latest sessions with title, project, model, relative time, cost, and tokens — so you can pick up right where you left off.

Usage overview

Streak, active days, today's steps, prompts, sessions, total cost, tokens, and subagents — the numbers that add up over time.

Activity heatmap

A GitHub-style contribution graph of your daily agent steps, so you can see momentum and quiet stretches in one glance.

Token mix

Input, output, reasoning, and cache read/write broken out into a single stacked bar, so you can see where the tokens go.

Models & tools

Per-model steps and cost, plus a tool-call success/failure breakdown — including how much work went to subagents.

Install

Get started

Build a local .app bundle and drop it in your menu bar. No App Store, no signing hassle.

  1. Clone the repository

    Grab the source — it's a single Swift package with no runtime dependencies.

  2. Build and launch

    make run compiles the release binary, assembles and ad-hoc signs dist/OpenCodeBar.app, then opens it.

  3. Keep it around (optional)

    Add the app in System Settings → General → Login Items to have it start with your Mac.

zsh — build 
$ git clone https://github.com/403access/ai-tools.git
$ cd ai-tools
$ make run

Under the hood

How it works

OpenCodeBar is a thin, read-only client over the OpenCode HTTP API.

01

Finds the service

Reads the password from service.json and discovers the local port via the OpenCode CLI.

02

Authenticates locally

Speaks HTTP Basic auth over loopback — the same flow the TUI uses. Nothing leaves your machine.

03

Polls a few endpoints

Sessions, active sessions, projects, and aggregate stats — the read-only surface, and nothing more.

04

Streams live events

Subscribes to the SSE event stream for instant updates, and reconnects automatically if the service moves.
